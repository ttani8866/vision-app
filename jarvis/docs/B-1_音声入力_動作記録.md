# フェーズB ステップ1 音声入力 動作記録（2026-09-13）

## 結果
- faster-whisper（small / CPU int8）で日本語文字起こしが動作
- テスト音声（Windows TTS Haruka、8.86秒）: 推論 2.5〜2.7秒、モデル読込 2.1秒
- 初回のみモデルダウンロードに約6分（約480MB）
- 既定マイクからの3秒録音: 正常（RMS 0.003、環境音レベル）

## 詰まりと対処
- コンソールがcp932で文字化け → stdout/stderr を UTF-8 に reconfigure
- 「KANBEI」→「完璧」、「新東通信」→「浸透通信」に誤変換 → initial_prompt に固有名詞の語彙ヒントを渡して解消
- Windows の symlink 警告（Developer Mode 未有効）→ 動作には影響なし。無視可

## 次のステップ
- B-2: 文字起こしテキストを KANBEI（Claude Code）へ渡す接続。`claude -p` の呼び出しから始める
- B-3: VOICEVOX を導入して音声出力。ElevenLabs は声の作り込み段階（フェーズE）で判断
- B-4: B-1〜B-3 をループ化（Push-to-talk → 文字起こし → KANBEI → 読み上げ）
