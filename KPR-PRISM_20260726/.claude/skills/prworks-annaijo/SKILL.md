# PRWorks-Annaijo（取材案内状作成）

## このスキルは何のためのものか

記者発表会・内覧会・試食会・オープニングセレモニーなどのメディア向けイベントで、取材を誘致する案内状を作る担当者が読む。「何を書けば来てもらえるか」「何を書き漏らすと当日事故になるか」の基準。

## 中身（ルール・型・ノウハウ）

### 1. 取材案内状の位置づけとタイミング

- 取材案内状は、記者会見や内覧会などの実施にあたり、取材を誘致するためにメディアへ配信する資料。
- メディア向けイベントは毎日多数開催されており、記者は数多くの案内の中から取材先を選別する。ニュース価値を吟味してもらう時間を確保するため、**イベント実施の2〜3週間前には配信する**のが理想。
- 各担当者はギリギリまで取材対象を選ぶため、**出欠の返事が前日になることも多い**。返事が遅いこと自体は異常ではない。出欠確認の電話フォローを計画に織り込む。

### 2. 押さえるべき2要件

1. **報道価値がわかるタイトル**であること。「取材案内状」である旨とイベントタイトルを明記した上で、対象メディアにとって報道する価値があることが伝わる表現にする。
2. **5W1Hが記載されている**こと。日時（When）／場所（Where）／主催・登壇者（Who）／イベントの目的（Why）／当日の内容（What）／流れ（How）。

### 3. 作成チェックポイント（10項目）

| 項目 | 確認内容 |
|---|---|
| ①タイトル | 「取材案内状」と明記したか。イベントタイトルはあるか。報道価値が表現できているか |
| ②ビジュアル | イベントで**撮れる「画」**を魅力的に感じてもらえるよう、重要ポイントの描写または参考ビジュアルを掲載したか |
| ③リード | 5W1Hが簡潔にまとまっているか |
| ④取材参加方法 | 先着順か抽選かを記載したか（抽選はメディア競争が激しそうな場合や待機スペースがない場合に検討） |
| ⑤著名人参加時 | 囲み取材・個別取材の**有無**を記載したか。写真・プロフィールを掲載したか |
| ⑥注意事項 | 撮影不可の対象、Web用動画撮影の可否、有料コンテンツへの配信可否など、**NG事項を事前に明記**したか |
| ⑦地図 | 取材場所の地図はあるか。**使用地図は著作権法に違反していないか**。FAXでも見やすいか |
| ⑧駐車場 | 有無を記載したか（テレビの中継車・機材車を想定） |
| ⑨問い合わせ先 | 電話番号、返信用FAX番号・メールアドレスに誤りがないか |
| ⑩可読性 | FAX送付も想定し、**モノクロ印刷でも見やすい**か |

### 4. 「撮れる画」の書き方

テレビ・写真媒体の出欠は「何が撮影できるか」でほぼ決まる。文章での説明に加えて、次を具体的に書く。

- フォトセッションの有無と内容（登壇者の並び、商品との絡み、演出）
- 囲み取材・ぶら下がり取材・個別取材の有無（芸能系はフォトセッション必須。囲み・個別の有無でメディアの反応が変わる）
- 実演・実食・体験など動きのあるコンテンツ
- インサート撮影が可能な対象（施設・製造工程・商品カットなど）

### 5. 配布ルート別の手順

- **記者クラブへ配布する場合**：リリースや取材案内の配布は、事前に幹事社の了承を取ってから直接持ち込むのが原則。クラブごとに受付ルール（48時間前ルール等）が異なるため必ず事前確認する。PR会社の代理持ち込みを禁じるクラブも多い。
- **個別メディアへ配信する場合**：メディアリストからイベントのテーマ・撮れる画に合う媒体をセグメントして送る。配信後、優先度の高いメディアには電話でフォローし、企画会議のタイミングに合わせて再アプローチする。
- 抽選制にする場合は、抽選券・封筒等の運営準備（`prworks-unei-manual`）と整合を取る。

### 6. 案内状に書いたことは当日の約束になる

案内状に記載したNG事項・取材参加方法・囲み取材の有無は、当日の運営マニュアル・進行台本（`prworks-daihon`）と完全に一致させる。案内状で「個別取材あり」と書いて当日実施しない、あるいは案内状にないNGを当日に後出しする、はメディアとの信頼を直接損なう。

## やってはいけないこと（NG）

- **撮れる画の記載がない案内状**。テキストだけの概要説明では、テレビ・写真媒体は出欠判断ができない。
- **NG事項の後出し**。撮影不可対象や配信制限は案内状の段階で明記する。当日に初めて伝えるのはトラブルの元。
- **フリー素材でない地図・地図アプリのスクリーンショットの無断転載**。地図には著作権がある。
- **著名人登壇イベントで囲み・個別の有無を書かない**。この情報がないと芸能系メディアは動けない。
- **解禁前情報の書きすぎ**。案内状は多数のメディアに渡る。発表当日まで伏せるべき内容（提携先名・出演者名など）は「当日発表」とし、情報管理を優先する。
- **カラー前提のデザイン**。FAX・モノクロ印刷で判読できない案内状は届いていないのと同じ。

## 止める基準

- イベント本番まで2週間を切っているのに案内状が未配信（配信計画から見直す）。
- 著名人の登壇・写真掲載・囲み対応について、本人・所属事務所の確認が取れていない。
- 会場のNG事項（施設側の撮影規定・ドレスコード等）を確認していない。
- 案内状の記載内容と運営マニュアル・進行台本の内容に食い違いがある。
- 記者クラブ配布なのに幹事社の了承を取っていない。
