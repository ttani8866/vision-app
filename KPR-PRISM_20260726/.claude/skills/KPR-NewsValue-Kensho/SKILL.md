# KPR-NewsValue-Kensho（PR検証スキル）

## このスキルは何のためのものか

**できあがった企画書・提案書・リリースを提出前に点検し、問題点を「指摘」する**ためのスキル。役割は、ニュースにならない要因・NG・炎上リスクを見つけて、直し方のアドバイスまで返すこと。

- このスキルは **ランク付け（A/B/C/D）や合否判定、差し戻しはしない**。「各項目に照らしてどうだったか」「NGはないか」を指摘し、改善のアドバイスを添えるところまで。最終判断は人が行う。
- 前段の分析は **KPR-Kikaku-Bunseki**、企画書の作成は **KPR-Kikakusho-Sakusei** が担当。このスキルは書く・分析するのではなく「チェックする」。
- 大前提：**報道の決定権はすべてメディア側にある**。企業が「良い情報だ」と思っても、外部・読者・マスコミの視点で価値がなければパブリシティは成立しない。企業の独りよがりを提出前に見つけて指摘するのがこのスキルの役割。

点検は次の順で行う：**STEP 0（最低条件）→ STEP 1（社会性）→ STEP 2（価値変動6要素）→ STEP 3（メディア視点の実地テスト）→ STEP 4（指摘のまとめ＋改善アドバイス）→ STEP 5（広報計画の品質）→ STEP 6（提出可否チェック）**。

## 中身（ルール・型・ノウハウ）

### STEP 0：ニュースの最低条件チェック

以下の4条件を満たさない情報は、どれほど演出しても報道されない。**満たしていない項目があれば、その点をはっきり指摘する**（点数はつけない）。

| # | 条件 | 見るポイント |
|---|---|---|
| 1 | **事実である** | 数字・固有名詞・実績の裏付け資料があるか。誇張・見込みを事実のように書いていないか |
| 2 | **新しい**（未報道・広告未出稿） | **外部検索で既報チェックを必ず行う**（企画の核となるキーワード＋企業名で検索。他メディアで既報、または広告出稿済みならニュースにならない） |
| 3 | **主観・自己主張・イメージ訴求が強すぎない** | 「最高の」「画期的な」等の形容詞を除いても情報が成立するか。客観的事実に立脚しているか |
| 4 | **情報発信者に信頼感がある** | 発信主体（企業・団体・専門家）が語る資格のあるテーマか |

**外部検索の使いどころ（このステップで必須）：**
- 「日本初」「業界初」「世界初」を謳う場合 → 必ず検索で裏取りする。**先行事例が1件でも見つかったら、表記を落とすか「国内○○業界初」等に限定するよう指摘する**
- 既報チェック → 「企業名＋企画キーワード」「商品名」で検索し、過去記事の有無を確認
- トレンド主張の実在確認 → 「○○が流行している」と書くなら、直近の報道量・調査データ・検索動向を検索で確認し、根拠として引けるソースがあるか見る
- 競合の類似発表の有無 → 直近3〜6カ月に競合が同種の発表をしていれば「二番煎じ」と見なされるリスクを指摘に含める

### STEP 1：社会性の検証（PRストーリー構造チェック）

ニュース価値の源泉は「社会性」＝その情報が世の中にとってどれだけ重要か。商品情報そのままは一方的な情報提供であってPRではない。

**1-1. 社会性の4類型のどれに接続しているか（最低1つ）**

| 類型 | 構文 |
|---|---|
| ① トレンド | 「今、○○が流行っている中、最先端の△△が登場」 |
| ② 生活者ニーズ | 「○○で困っている人が多い中、悩みを解決する△△が登場」 |
| ③ 世の中の気運 | 「○○な気運が高まる中、それを後押しする△△が登場」 |
| ④ 社会的課題 | 「課題視されている○○を解決する△△が導入」 |

○○（社会背景）に**客観的根拠**（調査データ、検索サジェスト、SNS言及、報道量）が添えられているか確認する。根拠のない「○○の気運が高まる中」は後付けのこじつけであり、記者に見抜かれる点を指摘する。

**1-2. 「問いかけ→答え」構造になっているか**
- 商品・サービス（＝答え）に対して、それが答えになる社会的「問いかけ」（社会課題／生活者の悩み）が先に提示されているか
- 例：「夏のオフィス冷え性に悩む女性が70%」（問いかけ）→「夏専用メッシュ腹巻き」（答え）
- 問いかけが弱い・無い企画は、答え（商品）がどれほど良くても際立たない点を指摘する

**1-3. 順張り／逆張りの設計が明示されているか**
- 順張り（大きな流れに乗る）：話題になりやすいが二番煎じリスク → 競合の先行発表を検索確認
- 逆張り（流れの真逆を行く）：面白い話題になるが共感を得られないリスク → 潜在ニーズの根拠データがあるか見る
- どちらでもない（社会の流れと無関係）→ 社会性が弱い点を指摘する

**1-4. Speed（タイミング）**
- 社会課題・トレンドの発生／顕在化タイミングと発表時期が合っているか。旬を過ぎたテーマへの接続は弱点として指摘する

### STEP 2：価値変動6要素の確認（発表条件の最適化）

ニュース価値は**絶対価値ではなく相対価値**。その日の需給関係で扱いが決まる相場商品である。同じ企画でも発表条件で記事の大小が変わるため、以下6要素を提案書のスケジュール・体制と照合し、最適化の余地があれば指摘する。

1. **NEW**：情報の鮮度。ただし「きわめて古いこと」が逆に新鮮でニュースになる場合もある
2. **独占性**：特ダネ＞独自ダネ＞三紙レク＞一斉発表の順に価値が下がる。1社独占なら3段記事、一斉発表ならベタ記事になり得る。企画の狙い（広く浅く／深く大きく）と発表方法が整合しているか
3. **相場性**：ニュースの少ない日を狙えているか。大型イベント・他社大型発表と重なる日程は弱点
4. **地域性**：競争の少ないエリアでの発表を検討したか（東京→大阪→名古屋→福岡→地方の順に競争が緩む）
5. **タイミング**：媒体の企画決定サイクル（雑誌は3〜2カ月前、TV特集は1週間前等）から逆算されているか
6. **発表者のランク**：社長＞副社長＞取締役＞部長。同じ内容でも発表者で記事の大小が変わる。企画の重要度に見合う登壇者・スポークスパーソンが設定されているか

---

### STEP 3：メディア視点の実地テスト

**3-1. 想定記事見出しテスト**
企画の内容で、**想定記事見出しを2本、実際の媒体トンマナで書けるか**を実際に書いて確かめる。
- ルール：固有名詞と数字を使う／30文字以内／業界の素人でもわかる言葉
- **見出しが書けない企画は、記者も書けない**。書けなければ「企画の核が定まっていない」点を指摘する
- 併せて想定SNS反応（ペルソナ付き）を3件書けるとなお良い

**3-2. ジャンル別の再判定**
ニュース価値はメディアのジャンルによって異なる。**経済面でダメでも生活面・女性誌なら面白い**ことがある。1つのジャンルで刺さらなくても、以下の属性特長9項目でどのジャンルに刺さるかを見てから指摘する：
①ユニーク（斬新・意外性）②人間味（生活感・日常性）③著名性 ④社会性 ⑤影響度・波及度 ⑥歴史性・記録性 ⑦国際性 ⑧地域性 ⑨専門性

**3-3. PR SPOTLIGHTS対応チェック**
素材に光を当てて、ニュースに変える10の視点｜共同ピーアール

企画・各施策がPR SPOTLIGHTSのどの視点に応えているかを確認する。**10視点すべてを網羅する必要はない**が、どれにも対応しない企画・施策は「メディアが取材する理由」が不明確なので、その点を指摘する。

10視点（S:Story／P:Public／O:Only／T:Trend／L:Local／I:Irony／G:Group／H:Hero／T:Term／S:Scene）の定義表は、**正本 `.claude/skills/KPR-Kikakusho-Sakusei/reference/pr-spotlights.md` を参照する**（作成スキルと共用の単一正本。このスキル側に表の複製を持たない）。

**3-4. 5W1H＋YTT＋映像性**
- 6W5H（Who/What/Why/Where/When/Whom＋How/How much/How many/How long/How is future）が埋まるか
- YTT（Yesterday これまで／Today 現在／Tomorrow 将来予測）の背景情報が語れるか
- **映像性**：テレビ・Webを狙うなら「何が撮影でき、誰に取材できるか」＝撮れる「画」と場があるか。画のない企画はTV露出の期待値が下がる点を指摘する
- テレビ・新聞を狙うなら「トレンドの証拠」（途切れない行列、驚くべき数値、著名人のレコメンド）が用意できるか

**補助レンズ：記者が食いつく6つの切り口**
①企業姿勢 ②技術革新 ③好評 ④協業 ⑤世代 ⑥歳時（＋人物ネタ）のどれかに言い換えられるか。1つも言い換えられない企画は、記者への説明が難しい点を指摘する。

### STEP 4：指摘のまとめ＋改善アドバイス

**返し方**
ランクや合否はつけない。代わりに、次を返す。
- **NGの有無**：STEP 0〜3で見つかった「これがあると報道されない／出せない」項目を列挙する。
- **各項目に照らした結果**：最低条件・社会性・価値変動6要素・実地テストの各観点で、どこが問題で、どこは問題ないかを具体的に述べる。
- **改善アドバイス**：下記「価値づけの定石」から、この企画に足せるものを提案する。

**価値づけの定石（企画を引き上げるアドバイス）**
ニュース価値はゼロサムだが、付加価値（プラスα）で増大は可能。以下から企画に足せるものをアドバイスする：
1. **調査データを足す**：関連アンケート調査で「言われてみれば確かに」「こうかと思ったら違った」のファクトを作る（調査PR化。サンプル数の目安は KPR-Kikaku-Bunseki の成立条件に従う）
2. **第三者のお墨付きを足す**：専門家コメント、有識者監修、公的機関のデータ引用で信頼性を上げる
3. **「並び」の事例を足す**：自社1社に限定せず他社事例と並べて「世の中的ムーブメント」として提示（ニュースレター型）
4. **発表者ランクを上げる**：部長発表→社長発表に変更
5. **タイミング・地域を変える**：ニュースの少ない日程、季節・時事イベントへの接続、競争の少ないエリアでの先行発表
6. **人物を立てる**：経営者・開発者の想い（ヒト・コト）を加え、モノだけの情報から脱却する
7. **画と場を作る**：内覧会・体験の場・メディアツアー等、撮影・取材できる状況を新設する

**記録しておくとよいこと**（任意）
- 点検日／点検者／対象企画名
- 既報チェックの検索クエリと結果
- 見つかったNG・弱点と、返したアドバイス

### STEP 5：広報計画としての品質チェック（11項目）

ニュース性（STEP 0〜4）とは別に、**提案書全体が広報計画として成立しているか**を点検し、外れている項目を指摘する。

1. 企業理念・経営戦略・コミュニケーション原則に立脚しているか
2. 年度・中期・長期計画とリンクしているか
3. 目標は明確・具体的（できる限り数値目標）か
4. 目標のプライオリティは明確か（総花的な目標羅列はどれも達成度が低くなる）
5. 目標とテーマは適合しているか
6. テーマ・訴求ポイント・手法・ツールは実現可能か
7. 現状調査（オーディット・ヒアリング）の結果は反映されているか（＝KPR-Kikaku-Bunseki の材料が使われているか）
8. 立案前に部外・社外の意見を聞いたか
9. 対象と目標、テーマ、手法、ツールのバランスは取れているか
10. 全体の広報戦略・コンセプトに問題はないか
11. 人員・予算は予測される効果（目標）にフィットしているか

### STEP 6：提出可否チェックリスト（成果物の最終点検）

成果物が提出できる状態か、点検者の視点で現物を確認し、外れている項目を指摘する。

1. [ ] 与件・課題・分析（KPR-Kikaku-Bunseki の材料）が第1部に正しく反映されている
2. [ ] 「広告ではなくPRである理由」がBefore/Afterで示されている
3. [ ] 施策は社会性（4類型）に接続し、順張り/逆張りの選択に根拠がある
4. [ ] 各施策が対応する PR SPOTLIGHTS の視点が明示され、固有の施策ネームが付いている
5. [ ] 各施策が「コンセプト→実行ステップ→ニュースメイク」の3枚で構成されている
6. [ ] 想定記事見出し・想定SNS反応が「想定/イメージ」明記で書かれている
7. [ ] 実名パートナー・専門家が「候補」と明記されている（確定と誤読されない）
8. [ ] 「掲載保証」と読める表現がない
9. [ ] 数値（市場データ・調査結果・費用）に出典がある
10. [ ] 効果測定が量×質で設計され、広告換算値が唯一のKPIになっていない
11. [ ] リテーナーの体制・ワークフロー・費用（SOW）が明示されている

## 指摘の際に見落としてはいけないこと（NG）

以下は「あれば必ず指摘する」項目。ここでも合否判定・差し戻しはせず、問題点と直し方を伝える。

- **企業視点だけで良し悪しを見ている**：「クライアントが伝えたいこと」の熱量を価値と混同しない。判断軸は常に外部・読者・マスコミの視点。
- **形容詞を価値の根拠にしている**：「画期的」「最高級」「こだわりの」等の主観表現は根拠にならない。数字・固有名詞・第三者データがあるかを見る。
- **裏取りなしの「日本初」「No.1」**：検索で先行事例確認がされていない新規性・至上性の主張。No.1表記は調査出典・調査条件の明記がなければ景表法リスクも併発する。
- **社会性の後付けこじつけ**：根拠データのない「○○の気運が高まる中」構文。記者は日常的にこの手のこじつけを見ており、常連になるとリリースの封も切られなくなる。
- **ニュース価値を絶対視している**：「良い企画だから必ず載る」は誤り。相場性・タイミング・独占性で扱いは変動する前提で期待値を伝える。
- **1ジャンルで刺さらないから全体×と見ている**：経済面で弱くても生活面で刺さり得る。ジャンル別再判定（STEP 3-2）を経ずに落とさない。
- **広告換算的発想で「価値がある」と正当化している**：広告換算値はコミュニケーションの価値ではない（バルセロナ原則）。露出見込み金額はニュースバリューの根拠にならない。
- **既報・広告出稿済みの情報をホットニュース扱いしている**：発覚すればメディアとの信頼関係を毀損する重大タブー。
- **総花的な目標羅列**：プライオリティのない目標はどれも達成度が低くなる。期間ごとの優先順位が明示されているか。
- **「掲載保証」と読める表現**：報道の決定権はすべてメディア側にある。掲載可否の確約・掲載前チェックを前提とした記述があれば指摘する（成果報酬型の契約条件は別途明示されているか）。

## 特に念入りに指摘すべきポイント

以下は見つけたら**必ず指摘に含める**（合否判定や差し戻しはしない。問題点と直し方を伝えるだけでよい）。

1. **事実性の裏付けがない**（STEP 0-①）。
   - ※「新規リリース（未報道の新情報）」であること自体は問題ではない（むしろSTEP 0-②で必要）。指摘すべきは「新しいかどうか」ではなく「その内容の**事実性を示す資料がない**」場合。両者を混同しない。
2. **「日本初」「業界初」「No.1」の裏取りが取れない**、または検索で先行事例・反証が見つかった（表記変更を提案する。景表法リスクも併発）。
3. **社会性の根拠データが存在しない**のに社会背景が語られている（調査PRでファクトを作るか、企画の核を見直すよう提案する）。
4. **想定見出しが2本書けない**（企画の核が定まっていないサイン）。
5. **炎上・危機管理リスクの兆候**：優良誤認・比較表現・ステマ規制への抵触可能性、逆張り／社会的にセンシティブなテーマへの安易な接続。必要に応じて法務・危機管理担当への相談を促す。
6. **費用・体制（SOW）が自社標準と乖離**する。ここでの「自社標準」とは KPR の標準SOW／料金表・標準ワークフローを指す（※標準ドキュメントの所在は社内で明示・共有しておくこと）。
7. **クライアントの意向とメディア視点が食い違う**。どちらかを握りつぶさず、両論と改善案を添えて伝える。
