# KPR-Kikaku-Bunseki（PR企画分析スキル）

## このスキルは何のためのものか

PR企画書を書く**前段**で、与件・市場・競合・課題・露出状況を分析し、**企画書作成スキルが「分析済み前提」で書けるだけの材料をそろえる**ためのスキル。ここが弱いと「ちゃんと調べた提案」に見えず、全体が崩れる。出力は次工程（KPR-Kikakusho-Sakusei）への引き渡し材料になる。

このスキルは「材料をそろえる」ことに専念する。企画書の執筆・ニュース性の最終判定は行わない（それぞれ作成スキル・検証スキルの役割）。

## 参照元エージェント（フル版 KPR-AgentOS の該当エージェント）

※本ライト版パッケージには以下のエージェント本体は含まれない。フル版（`20260718検証/KPR-AgentOS/`）を併用する場合の対応関係として記載する。

- **KPR-PRStrategist**：与件整理・課題分析・3C/STPの実務手順として参照する
- **KPR-Senryaku**：ストーリー設計の前提となる分析材料の要件定義に参照する
- **KPR-Bunseki**：露出分析・報道内容分析・調査PR成立条件の観点として参照する（SAKAEデータ分析と併用）

---

## 分析の全体フロー

```
① 与件整理（6項目） → ② 課題分析（生活者の障壁へ翻訳）
→ ③ 3C分析 → ④ 競合分析 → ⑤ STP（ターゲット・立ち位置）
→ ⑥ 露出分析・報道内容分析 → ⑦ メディア事前ヒアリング
→ ⑧ 調査PR成立条件の確認（※該当時のみ・不要ならスキップ）
→ ⑨ 分析材料の引き渡し
```

---

## 1. 与件整理（6項目）

依頼を1枚で6項目に整理する。ここが埋まらないまま先へ進まない。

1. **現在地**（今どういう状態か）
2. **目指す世界**（達成したいゴール）
3. **背景**（なぜ今この依頼か）
4. **課題**（ターゲット層×アプローチ不足の形で特定）
5. **依頼事項**（クライアントが求めていること）
6. **予算**

## 2. 課題分析（生活者の障壁への翻訳）

- 課題を**「生活者の障壁」**に翻訳する：「障壁① そもそも、思い出されない」のように、**短い話し言葉の見出し＋2行の説明＋根拠**（検索サジェスト・SNS言及・調査データ）を2〜4個。
- 各障壁に**根拠**を必ず添える。根拠のない障壁は後工程で使えない。
- **課題×打ち手の対応マップ**の素地を作る（打ち手の確定は作成スキル側で行う）。
- 課題分析が甘くならないよう、障壁ごとに一次データ／検索・SNSの実測を1つ以上つける。

## 3. 3C分析（戦略の入口）

- **Customer**：市場規模・推移・成長性／購買行動／顕在・潜在ニーズ／不満・不安
- **Competitor**：シェア／戦略・リソース／ポジション／強み・弱み／歴史・ストーリー資産
- **Company**：理念・ビジョン／既存事業の現状／強み・弱み／ヒト・モノ・カネ
- 狙いどころ＝「**需要があり、自社の強みを活かせて、競合がいない**」場所を特定する。

## 4. 競合分析

- **クライアントの構造優位を分析**：「従来は○○という構造→当社は△△」の**対比構文**で3〜4点。後の施策（裏側How系）の素材になる。
- 競合の直近3〜6カ月の発表・露出を確認し、**二番煎じリスク**の有無を材料化する。
- 競合他社の情報・比較は**出典が公開情報であることを確認できたものだけ**を材料にする（確認できないものは載せない）。

## 5. STP分析（ターゲットと立ち位置）

- **Segmentation**：最重要は「**どの年齢・性別の人が、どんな理由で、どんなタイミングで使うか**」（年齢・性別・購入動機・タイミングの4点）で分けるのが最も汎用的。
- **Targeting**：使える道具は3つ
  - ペルソナ（名前・年齢・居住地・職業・年収・趣味・性格・志向性まで実在レベルに設定）
  - マーケティングファネル（認知→興味→比較検討→アクション→ファン化→共有。**どの階層に課題があるか**で打ち手を判断。デュアルファネルでLTVまで見る）
  - イノベーター理論（キャズム＝アーリーアダプター13.5%とアーリーマジョリティ34%の間の溝。キャズム超えにはマジョリティに影響力のあるメディア露出・インフルエンサー・アンバサダー）
- **Positioning**：2軸マップ（一軸＝機能的価値、もう一軸＝情緒的価値など相関の低い軸）。USPを鑑みて優位性を作れる軸を設定し、**ブルーオーシャンか、強みを特化できる場所**に置く。

## 6. 露出分析・報道内容分析（説得力の肝）

PR企画書の説得力はここで決まる。「ちゃんと調べた提案」に見せるための中核。

- **記事クリッピング／露出分析**：クライアント・競合・カテゴリーの過去報道を収集し、量（本数・媒体数）と質（媒体種別・論調・切り口）で整理する。
- **外部ツールの結果を活用する**：クリッピング・露出分析は外部ツールの出力を添付・引用して使う（ツール結果は出典として明記）。手作業で全量を作り込まない。
- **報道内容分析の観点**：どの切り口で報じられているか／未報道の切り口はどこか／競合はどのメディアに強いか。**未報道の切り口が、企画の「新しさ」の根拠になる**。
- ここで得た「既報の有無」は、後の検証スキル（KPR-NewsValue-Kensho）STEP 0（新規性チェック）へ引き継ぐ。

## 7. メディア事前ヒアリング（独自調査）

- リレーションのあるメディア関係者への事前ヒアリングの生の声をテーブルで提示（媒体／ターゲット／クライアント認知○×／第一印象／コメント）。
- ジャンルはTV・新聞・雑誌等で分散させる。ここで得たコメントが**後の施策の必然性の根拠**になる。

## 8. 現状診断の道具（大型・リテーナー提案時）

- **オーディット**（企業広報環境調査）の5調査：①報道状況調査（競合比較報道分析）②広報活動調査 ③企業イメージ調査 ④マスコミ・オピニオンリーダーヒアリング ⑤広報環境予測分析。
- 1回では現状把握のみ。**1〜3年ごとの定点観測で初めて効果測定になる**ことを提案に織り込む（提案化は作成スキル側）。

## 9. 調査PR成立条件の確認（該当時のみ）

調査リリース（調査PR）は毎回行うものではない。**次のいずれかに当てはまるときだけ**このステップを実施する。当てはまらなければスキップしてよい。

- クライアントから調査リリースの要望がある
- 既存の材料だけではニュース性が不足し、ファクトを新たに作る必要がある

上記に該当し、調査PRを施策化する場合のみ、以下の成立条件を確認する。

- **サンプル数の目安**（※社内ナレッジとして要検証・要更新）：
  - 基本は **400** サンプルを一つの目安とする
  - 運用上 **500** とすることもある
  - 新聞狙いなど信頼性を高く求める場合は **1000以上** の実務知もある
  - → これらは全員の共通知ではないため、案件ごとに社内知見を確認・明文化する
- **設問設計**：誘導的な設問になっていないか。フックは「言われてみれば確かに」と「意外性」。
- サンプル数が目安を満たせない／設問が誘導的になりそうな場合は、作成前停止（下記）に従う。

## 分析材料の引き渡し（このスキルの出力）

作成スキルに渡すため、最低限以下をパッケージ化する。

- 与件6項目（現在地／目指す世界／背景／課題／依頼事項／予算）
- 生活者の障壁2〜4個（各根拠つき）＋課題×打ち手対応マップの素地
- 3C分析結果と「狙いどころ」
- クライアントの構造優位3〜4点（対比構文）
- STP（セグメント・ペルソナ・ファネル上の課題階層・ポジショニング軸）
- 露出分析／報道内容分析（外部ツール結果の添付＋未報道の切り口）
- メディア事前ヒアリングの声
- 調査PRを行う場合の成立条件（サンプル数・設問方針）

---

## やってはいけないこと（NG）

- **推測で与件を埋めない。** 「課題」「予算」が不明なまま分析を先へ進めない。ヒアリングに戻す。
- **根拠のない社会背景を作らない。** 「○○の気運が高まる中」を、調査データ・検索・SNS・報道量の裏付けなしに書かない（後付けこじつけは記者に見抜かれる）。
- **出典不明の競合情報・比較を材料にしない。** 公開情報であることを確認できないものは載せない。
- **クライアントの機密／未発表情報を勝手に分析材料へ入れない。** 取り扱い可否を確認する。
- **数値（市場データ・調査結果）を出典なしで書かない。**

## 止める基準（作成前停止＝入力不足）

以下に該当したら、作成スキルへ進まず、担当者・上長・クライアントに確認する。

1. **与件6項目のうち「課題」「予算」が埋まらない**：推測で書き始めない。
2. **調査PRを行うのにサンプル数の目安を満たせない**、または設問が誘導的になりそう。
3. **機密／未発表情報の取り扱いが明記されていない**：取り扱い可否を確認する。
4. **競合情報など必要な入力が欠けている**、または出典を公開情報と確認できない。
5. **露出分析・報道分析の材料が入手できない**：外部ツール結果の入手可否を確認する。
