# KPR-Kikakusho-Sakusei（PR企画書作成スキル）

## このスキルは何のためのものか

**必要な分析（与件・課題・3C/STP・露出分析等）はすでに揃っている前提**で、その材料を使って企画書を**上手に組み立てて書く**ためのスキル。位置づけは「分析済みの材料を受け取り、構成・戦略・施策・書きぶりを設計する“書く人”」。

**着手前チェック**：分析材料（与件6項目／障壁／3C/STP／露出分析／ヒアリング）が揃っているか。揃っていなければ KPR-Kikaku-Bunseki に戻す。

## 作成の作業手順

```
① 分析材料の受領・確認 → ② 戦略（方向性・コンセプト・メッセージ）の導出
→ ③ PRストーリー開発 → ④ 施策設計（戦術）
→ ⑤ メディアプラン・スケジュール → ⑥ 効果測定設計
→ ⑦ 体制・費用の記述 → ⑧ 6部構成への落とし込み
→ ⑨ 検証スキルへ引き渡し
```

- **戦略**＝分析から方向性・コンセプト・メッセージを決めるシナリオ（何をするか／**しないか**）。
- **戦術**＝戦略をどのやり方で実現するか（施策のストーリーと具体案）。
- 戦略と戦術に**一貫性がなければ企画書は成立しない**。常に全体を意識する。

## 提案書の標準構成（6部構成＝最終成果物）

| 部 | 役割 | 内容 |
|---|---|---|
| 第1部 与件整理と課題分析 | 「正しく理解している」ことを示す | 与件整理／クライアント理解／課題の構造化／独自調査／PRの必然性（材料は KPR-Kikaku-Bunseki より） |
| 第2部 提案骨子 | 提案の見取り図を示す | PR活動のステップ論／提案の全体像／フレームワーク提示 |

## 1. 戦略の導出（方向性・コンセプト・メッセージ）

分析材料（3C/STP・課題）から、次を確定する。

- **方向性**：狙いどころ（需要×自社の強み×競合不在）に沿った打ち手の方向。
- **コンセプト**：提案全体を貫く一言。
- **メッセージ**：発信の3S（Stance／Story／Speed）を満たすか点検する（3Sの定義は、らしさ正本 `.claude/commands/kpr.md` §1-8を参照。KPR-PR-Shisouはライト版未収録）。
- **やらないことの明示**：総花的にせず、優先順位を決める。

## 2. PRストーリーの開発（企画の心臓部）

### 「問いかけ→答え」の構造
1. 商品・サービスを「答え」に設定する
2. それが「答え」になる社会的「問いかけ」（社会課題／生活者の悩み）を考える
3. 「問いかけ」と「答え」をつないで文章化する

問いかけ（例：夏のオフィス冷え性に悩む女性が70%）があるから答え（夏専用メッシュ腹巻き）が際立つ。**答えになる問いかけを複数探し出せる力がPRストーリー創造力**。

### 順張り／逆張り（ストーリーの型）
PR企画のポイント＝「社会性」×「順張り/逆張り」の掛け合わせ。
- **順張り**：「Aが広まる中、A+というサービスが始まった」— 話題になりやすいが二番煎じリスク
- **逆張り**：「Aが広まる中、真逆のBが始まった」— 面白いが共感を得られないリスク
- 両方書いてみて、ニュースバリューと共感可能性で選ぶ（最終判定は検証スキル）。

### ストーリーの素材＝ヒト・モノ・コト
モノ（商品の特徴・売上推移）だけでなく、**ヒト**（経営者の考え・開発者の想い）と**コト**（開発背景・市場動向）を素材化する。差別化＋親近感＋ファン化につながる。

### PR SPOTLIGHTS（施策体系化の骨格・10の視点）
**素材に光を当てて、ニュースに変える10の視点｜共同ピーアール**

「これは記事にしたい」と感じさせるメディアの心のツボ。**メディアが求める情報に変換しなければ、大量にリリースを打っても報道されない**。頭文字で「SPOTLIGHTS」を構成する10の概念（S:Story／P:Public／O:Only／T:Trend／L:Local／I:Irony／G:Group／H:Hero／T:Term／S:Scene）で、素材のどこに光を当てれば記事になるかを点検する。

**10視点の定義表（正本）は `reference/pr-spotlights.md` を参照する**（検証スキル KPR-NewsValue-Kensho と共用。定義を変更するときは正本のみを更新する）。

## 3. 施策設計（戦術パート）

### 手法マップ（引き出しの全体像）
- **報道資料**：プレスリリース（未発表ニュース）／ニュースレター（発表済みでも切り口で露出。生活者ニーズ×調査データ×「並び」事例の3点で厚みを出し、"いま"取材する理由を提供）
- **ファクト作り**：調査PR（設計→実査→分析→PRの4フェーズ、各1週間〜1カ月。サンプル数の目安・設問方針は KPR-Kikaku-Bunseki で確認済みの条件に従う）／啓発PR（潜在的問題→世の中ゴト化→ニーズ顕在化→自分ゴト化→商品PR）
- **コンテンツ**：CMPR／トップインタビュー／プレスキャラバン／プレゼントパブリシティ／プレースメント
- **イベント**：記者発表会（ビジネス系・芸能系）／プレスツアー／セミナー／内覧会（オープン3日以上前）／試食会／ポップアップ（1週間以上・そこにしかないもの）／記者懇親会（リレーション目的）／タッチアンドトライ
- **企画パブリシティ**（素材を創る）：募集企画／アンケート募集企画（募集と結果で二度使える）／セミナー・シンポジウム／プレゼント／パブリシティイベント
- **デジタル**：PESO（Paid/Earned/Shared/Owned）の組み合わせ。事前PR・事後PR・定期的PRの3タイミング。広告部署の状況もヒアリングし既存施策と連動させる

### アイデア発想の道具
アイデア＝既存の要素の組み合わせ。**マッチングリボン**（商材の特徴×ターゲットのインサイト・トレンドを各10個出して掛け合わせ）と**ニーズマンダラート**（商材の要素→ニーズに変換→ニーズを満たす別のモノと掛け合わせ）を使う。

### 施策の書き方（各施策3枚構成）
- **各施策が PR SPOTLIGHTS のどの視点に対応するかを明示する**。10視点すべてを網羅する必要はない。施策ごとに「この施策は S(Story)／O(Only) に光を当てる」のように、対応する頭文字を1〜数個ひも付ける。
- 各施策に**固有の施策ネーム**を付ける（トレンドワード型・企画名型・ハッシュタグ型。そのまま報道・SNSで使える名前）。
- **1枚目＝施策コンセプト**：見出し（対応するSPOTLIGHTSの頭文字＋「◯◯に応える」＋施策名）／リード1文／ポイント3つ（何をやるか・なぜ効くか・広がりの設計）／完成イメージ
- **2枚目＝実行ステップ**：3〜5ステップ（誰と交渉し、何を作り、いつ発信するか）。巻き込む専門家・パートナーは実名候補まで（「候補」と明記）。
- **3枚目＝ニュースメイク**：なぜメディアが取り上げるかの根拠2点／**想定記事見出しを2本**（実際の媒体トンマナで・「想定」明記）／**想定SNS反応を3〜4件**（ペルソナ名付き吹き出し・「イメージ」明記）。ここが提案書の熱量の中心。「露出後の世界」を追体験できる粒度で書く。

## 4. メディアプラン・スケジュール設計

- 媒体別リードタイムから逆算する：テレビ密着/ドキュメンタリー＝1カ月前〜／テレビ・Web・新聞の特集＝1週間前／ストレート＝1日前／雑誌＝月刊誌1.5〜2カ月前に内容決定→**3〜2カ月前アプローチ**／Webはローンチ後に鮮度が落ちるため**ローンチ前アプローチが肝心・画像必須**。
- テレビ・新聞は「トレンドを紹介する」メディア→**トレンドの証拠**（途切れない行列・驚くべき数値・著名人のレコメンド）を施策に組み込む。雑誌・Webは「トレンドを提案する」メディア。
- 大型発表の同日設計：記者クラブ（11時）→一般メディア記者発表会（13時）→業界紙発表会（15時）の順。一般メディアと業界紙は必ず分ける。
- タイムラインはクライアント側の既知イベント（旗艦店オープン等）も載せて統合感を出す。

## 5. 効果測定設計

- 施策実施の**前に**「どの指標で効果を見るか」の共通認識を持つ。企画書に必ず測定設計を入れる。
- **量**：露出メディア数／広告換算値／動画再生数／サイト訪問数／SNS投稿数
- **質**：認知度調査／好意度・意識調査／売上・来店数・購入数（対前年比）
- バルセロナ原則に準拠：アウトプット（露出）よりアウトカム（認知・意識変容・行動変容）を推奨。**広告換算値を唯一のKPIにしない**。
- 厳密測定は「露出数（量）×メディア種類別の重み（質）×露出の文脈（質）」のスコア方式（事前にランク設定）。
- 定点観測（1〜3年ごとのオーディット）を中長期提案に織り込む。

## やってはいけないこと（書きぶりのNG）

判定・品質のNGは検証スキルが持つ。ここは執筆時に守る書き方のNGに限定する。

- **商品スペックの羅列を「企画」と呼ばない。** 社会背景（○○）と商品（△△）が関連づいていない施策は一方的な情報提供でありPR企画ではない。
  - NG例：「高性能な新製品が出ます。リリースを配信します」
  - OK例：「テレワーク難民が続出する中（社会背景）、防音シェルターを発売（答え）」
- **戦略と戦術がバラバラな企画書を書かない。** 3C/STPで導いたターゲット・ポジションと無関係な施策を「面白いから」で入れない。
- **「問いかけ」のない「答え」だけのストーリーを書かない。** 必ず問いかけ（社会的背景・悩み）とセットにする。
- **想定記事見出し・想定SNS反応を「実在媒体の実記事」と誤認される形で書かない。** 「想定」「イメージ」を必ず明記する。
- **実現可能性のない実名パートナー・専門家を確定事項のように書かない。** 「候補」と明記する。
- **「掲載保証」と読める表現を書かない。** 報道の決定権はすべてメディア側にある（成果報酬型の契約条件は別途明示）。
- **数値（市場データ・調査結果・費用）を出典なしで書かない。**
- **広告換算値を唯一のKPIとして書かない。**

## 止める基準（作成中の差し戻し）

- **分析材料が揃っていない**（与件6項目・障壁・3C/STP・露出分析のいずれかが欠落）→ KPR-Kikaku-Bunseki へ戻す。
- **同一テーマのプロモートを複数メディアに同時に持ち込む設計**になっている → 1テーマ1メディア（ジャンルが違えば可）に直す。成功テーマの別メディア持ち込みはタブー。
- **費用・体制（SOW）が自社標準と乖離**しそう → 勝手に値引き・過剰スコープを書かず、上長へ確認。
- 完成後は必ず **KPR-NewsValue-Kensho** による検証を通す（品質・ニュース性・炎上の判定はそこで行う）。
