# PR SPOTLIGHTS — 素材に光を当てて、ニュースに変える10の視点｜共同ピーアール

**この表が正本（single source of truth）。** 企画書作成（KPR-Kikakusho-Sakusei）と提出前検証（KPR-NewsValue-Kensho）の両方がこのファイルを参照する。10視点の定義を変更するときは、必ずこのファイルだけを更新すること。

「これは記事にしたい」と感じさせるメディアの心のツボ。メディアが求める情報に変換しなければ、大量にリリースを打っても報道されない。頭文字で「SPOTLIGHTS」を構成する10の概念で、素材のどこに光を当てれば記事になるかを点検する。

## 10視点の定義表

| 頭文字 | 概念 | 意味（切り口） | 活用例 |
|---|---|---|---|
| S | Story | 物語・人間ドラマ・事例 | 開発秘話や顧客・導入事例を「一人の物語」としてドラマ化 |
| P | Public | 社会性・公共性 | 食品ロス／ジェンダー／脱炭素など社会課題と接続 |
| O | Only | 最上級・初・独自 | 世界初・日本一・独自調査「7割が勘違い」 |
| T | Trend | 時流・世相・季節性 | 「〇〇の日」「新生活」など歳時記・時流フック |
| L | Local | 地域性 | 地元発の話題を全国区へ・自治体のユニーク施策 |
| I | Irony | 逆説・意外性・対立構造 | 「常識では〇〇のはず、実は△△」のギャップ・VS構図 |
| G | Group | グループ化・カテゴリー化 | PR単品発表を「新カテゴリー誕生」「市場が動いた」と束ねる |
| H | Hero | 語り部・体現者・お墨付き | 社長・開発者・専門家の推奨・受賞・公的評価で信頼を担保 |
| T | Term | キーワード・数字 | 「名もなき家事」等の命名・「総製作費1億円超」 |
| S | Scene | 画になる・映像性・体験 | 体験会・実演・試食試乗など"撮れ高"になる体験の場を設計 |

## 使い方（局面別）

- **作成時（KPR-Kikakusho-Sakusei）**：施策ごとに、対応する視点の頭文字を1〜数個ひも付けて明示する。10視点すべてを網羅する必要はない
- **検証時（KPR-NewsValue-Kensho）**：企画・各施策がどの視点に応えているかを確認する。どれにも対応しない企画・施策は「メディアが取材する理由」が不明確なので、その点を指摘する
