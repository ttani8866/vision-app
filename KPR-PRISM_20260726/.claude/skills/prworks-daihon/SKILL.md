# PRWorks-Daihon（進行台本作成）

## このスキルは何のためのものか

記者発表会・PRイベント・オンライン発表会の進行台本を書く担当者が読む。台本は当日の関係者全員（MC・登壇者・運営スタッフ・技術）の共通指示書であり、露出の中身（登壇者が何を言い、何が撮られるか）を事前に設計する道具でもある。

## 中身（ルール・型・ノウハウ）

### 1. 式次第の型

**ビジネス系記者発表会**（新商品・新サービス・経営発表。参加メディア：情報番組ニュース班、経済部、文化部、生活部など）

```
MC挨拶 → 概要説明 → 登壇者プレゼン → 質疑応答
→ フォトセッション → 囲み取材／個別取材
```

**芸能系記者発表会**（話題喚起・認知向上。新CM発表など。参加メディア：情報番組芸能班、スポーツ紙、女性週刊誌、エンタメWebなど）

```
MC挨拶 → 概要説明 → CM上映 → 出演者登場演出 → トークセッション
→ 動きのある演出 → コメント → フォトセッション → ぶら下がり取材／個別取材
```

芸能系は著名人が登壇すること自体に価値があるため**フォトセッションは必須**。囲み・個別の有無でメディアの反応が変わる。取材案内状（`prworks-annaijo`）に記載した内容と完全に一致させる。

### 2. 台本に必ず入れる要素

1. **タイムテーブル**：分単位。各パートの開始・終了時刻、巻き／押しの調整ポイント。
2. **MC原稿**：挨拶、概要説明、登壇者紹介、質疑応答の仕切り、フォトセッションの誘導、締め。言い間違いが許されない固有名詞（社名・商品名・登壇者名・肩書）にはフリガナ。
3. **登壇者の動線**：入場・立ち位置・移動・退場。芸能系は登場演出のきっかけ（音響・照明・映像）を明記。
4. **上映・演出のきっかけ（キュー）**：CM上映、VTR、音響、照明の各キューを誰の合図で出すか。
5. **メッセージの落とし込み**：露出内容は登壇者の発言や行動で決まる。**伝えたいキーメッセージを、登壇者のコメント・トークの問いかけに具体的に落とし込む**。「自由に話してもらう」は設計放棄。
6. **質疑応答の設計**：想定質問表と回答（Q&A）。回答者の割り振り（どの質問は社長、どの質問は開発担当か）。答えられない質問への対応方針（「後日回答」の言い回しまで）。
7. **フォトセッションの指示**：並び順、目線の送り先、カメラマンからの掛け声への対応、小道具（商品・パネル）の持ち方、カット数と所要時間。
8. **囲み・個別取材の運営**：実施場所、対応時間、1媒体あたりの時間（個別）、同席者、NG質問への対応。
9. **NG事項**：撮影不可の対象・時間帯、質問NG領域、関係各所（事務所・提携先）のNG媒体。
10. **緊急時の代替進行**：登壇者の遅刻・急病、機材トラブル時の差し替え進行。

### 3. 会場設計の基準数値（台本の裏付け）

- **ENGカメラの三脚幅は約900mm**。テレビ4番組が出席する場合、カメラ設置場所は最低3600mm幅が必要。出席見込みから逆算してカメラ位置を台本の会場図に落とす。
- **芸能系のステージ高は400〜600mmが一般的。スチール撮影席の1列目はステージ前から約5m離す**と、あおり過ぎず遠すぎない画になる。最終的にはオフィシャルカメラマンと調整する。
- 質疑応答用のマイクランナーの人数・動線も台本に書く。

### 4. 取材対応まわりの設計

- 個別インタビューがある場合は、なるべく**事前に質問案を取り寄せて回答を準備**する（ただし、こちらから質問骨子の提出を強く要求するのはメディアに良い印象を与えないので慎重に）。
- インタビュー内容は後日の原稿確認に備えてメモ・録音に残す段取りを台本に含める。
- テレビ取材には1人つきっきりの対応スタッフを割り当てる。
- **取材が終わった直後が最もリスクが高い**。優秀な記者は気が緩んだ終了後の一瞬に最も重要な質問をする。登壇者への事前ブリーフィングでこの点を必ず伝える（台本の登壇者向け注意事項に記載）。

### 5. オンライン・ハイブリッド発表会

- プラットフォームの使い分け：対話型（Zoom等：Q&A・投票・参加者管理が可能）／一方向型（YouTube Live等：大規模向け、チャットのみ、タイムラグ30秒〜2分）。台本には**配信側のキュー**（配信開始・画面切替・ミュート管理・Q&A読み上げ）を現場進行と別レーンで書く。
- バックアッププラン（機材・プラットフォーム・ネットワークの二重化）と切替時の進行を台本に含める。詳細チェックリストは `kpr-oc-checklist` の本番前チェックに従う。

### 6. 作成・承認フロー

台本は「発表内容の確定 → 式次第 → MC原稿・Q&A → 関係者確認（登壇者本人・事務所・クライアント・技術）→ リハーサルで修正 → 最終版配布」の順で固める。記者会見は実施までに2〜3週間の準備期間を要する。想定問答は登壇者・責任者の承認を必ず取る。

## やってはいけないこと（NG）

- **キーメッセージをコメントに落とさず登壇者任せにする**。露出の中身が設計できていない台本は台本ではない。
- **案内状と食い違う台本**（囲み取材の有無、フォトセッションの内容など）。案内状の記載は当日の約束。
- **尺を詰め込みすぎる**。質疑応答・フォトセッション・転換の時間を削ると、露出機会そのものを削ることになる。
- **想定問答なしで質疑応答に臨ませる**。特にネガティブ・センシティブな質問の想定を省かない。
- **固有名詞のフリガナ漏れ**。MCの読み間違いは登壇者・クライアントへの失礼であり、収録されれば露出にも残る。
- **台本への解禁前情報の無防備な記載と配布**。配布範囲を管理し、外部スタッフ向けには必要情報のみの抜粋版を検討する。

## 止める基準

- 登壇者本人・所属事務所の内容確認（コメント・演出・囲み対応・NG事項）が取れていない。
- 想定問答が責任者承認を通っていない、またはネガティブ質問の想定が空欄。
- テレビ出席数に対してカメラ席・スチール席のスペースが物理的に足りない（会場図で確認）。
- リハーサルの時間が確保されていない。
- オンライン配信でバックアッププランが未設定。
