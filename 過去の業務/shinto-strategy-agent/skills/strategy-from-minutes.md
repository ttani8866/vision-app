# 議事録→戦略レポート生成スキル

## スキル概要
議事録データを受け取り、5体のエージェントチームが分業して戦略レポートを生成する。

## トリガー
「この議事録から戦略レポートを作って」「議事録を分析して」等の指示

## インプット形式（自動判別）
- テキストファイル（.txt / .md）
- Googleドキュメントのリンク
- 音声文字起こしサービスの出力テキスト（tl;dv、Otter等）
- 上記の混在（複数会議分の一括投入あり）

## 処理フロー

### Phase 0: 前処理
- 複数会議分のデータが含まれる場合、会議ごとに分離・整理する
- input/フォルダのファイルを読み込む、またはGoogleドキュメントリンクからテキストを取得する

### Phase 1: エージェント1（イシュー構造化）
- 表面的な要望と本質的な経営課題を分離する
- 課題を事業領域（広告/PR/データ/インフルエンサー）に分類する
- 「事業インパクト × 実行難易度」マトリクスで優先順位付け
- 出力：課題マップ、本質課題の仮説一覧

### Phase 2: エージェント2・3・4（並列実行）

#### エージェント2（市場・競合構造リサーチ）
- 課題領域の市場規模・成長率・構造変化を調査
- 競合ポジショニング、直近の打ち手、強み・弱みを整理
- 定量データを重視
- 出力：市場構造サマリー、競合ポジショニングマップ、機会・脅威の整理

#### エージェント3（顧客インサイト＆ペインリサーチ）
- ペルソナ2〜3パターン設定、ペインポイント特定
- PR視点（世の中ゴト化）、VAZ視点（Z世代リアリティ）を加える
- 出力：ペルソナ別ペインマップ、インサイト仮説リスト、世の中ゴト化の切り口

#### エージェント4（アナロジー＆クロスインダストリーリサーチ）
- 同業種・異業種・地方発の3層で構造類似事例を探索
- 歴史・地政学・文化的アナロジーを1つ追加
- 出力：アナロジー事例集、転用アイデアサマリー

### Phase 3: エージェント5（戦略統合＆レッドチーム）
- ステップA：エージェント1〜4を統合し戦略3案を立案
- ステップB：レッドチーム批判（実現可能性/PR成立性/ROI妥当性）
- ステップC：ブラッシュアップ、推奨戦略1案に絞り込み

### Phase 4: 最終レポート出力（PDF）
- エグゼクティブサマリー（1ページ）
- 課題構造の整理
- 市場・競合分析
- 顧客インサイト
- 参考事例
- 戦略提案（推奨案 + 代替案）
- レッドチーム批判とその対応
- 実行ロードマップ（3ヶ月/6ヶ月/12ヶ月）
- 新東通信グループのアセット活用マップ

## 出力先
output/フォルダにPDFとして自動生成
