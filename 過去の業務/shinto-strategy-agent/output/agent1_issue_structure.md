## B. 本質課題の仮説一覧（表面要望→本質課題の翻訳テーブル）

| # | 表面的な要望（発言内容） | 本質的な経営課題（仮説） |
|---|------------------------|------------------------|
| 1 | 「資料請求の質を上げたい」 | ファネル全体の歩留まり改善による成約効率の最大化。件数KPIから収益KPIへの経営指標の転換期にある |
| 2 | 「ディスプレイ広告経由の冷やかしが多い」 | ターゲティング精度の問題だけでなく、広告クリエイティブとLP上の期待値設定にミスマッチがある。認知施策と獲得施策の役割分担が曖昧なまま運用されてきた |
| 3 | 「認知がないと検索もされない」 | 認知の必要性は理解しつつも、認知投資のROIを可視化できていない。認知施策の効果測定フレームが不在 |
| 4 | 「A社のInstagramが上手い、うちもやりたい」 | 競合への焦りが起点だが、本質は「信頼コンテンツ」の不足。第三者（実際のオーナー）による推奨が成約に効くことを経験的に理解しており、UGC的な信頼構築を求めている |
| 5 | 「Instagramは費用対効果が一番良い」 | Instagram経由ユーザーの成約率が高いのは事実かもしれないが、ラストタッチ偏重の評価になっている可能性がある。正確なアトリビューション分析なしにチャネル間の予算判断をするリスク |
| 6 | 「広告臭くないコンテンツが欲しい」 | 従来型の押し売りクリエイティブでは共働き高感度層に響かないという肌感覚。コンテンツマーケティングへの移行ニーズ |
| 7 | 「LINE公式アカウントを活用したい」 | 単なるLINE運用の話ではなく、見込み顧客のナーチャリング基盤が欠如している。CRM/MA的な仕組みの導入ニーズ |
| 8 | 「ターゲットを絞りたい」 | 前年の「広く薄く」戦略の失敗認識。限られた予算で効率よく成約に至るためのセグメンテーション強化 |
| 9 | 「うちのホームページ、パッとしないよね」 | デジタル接点全体のブランド体験が時代遅れになっている自覚。ただし、LP単体ではなくサイト全体のUX問題に発展する可能性がある |

## C. 事業インパクト x 実行難易度マトリクス

縦軸：事業インパクト（高/中/低）
横軸：実行難易度（低=すぐできる / 中=一定の工数 / 高=時間・体制が必要）

### 高インパクト x 低難易度（最優先：Quick Win）

- ディスプレイ広告のターゲティング精査とメディアミックス再設計
  → 前年データがあるため、ROI分析に基づく配分変更は比較的容易
- LP改修（スマホファーストビュー最適化、写真差し替え）
  → 制作費800万の中で対応可能。効果が出やすい

### 高インパクト x 中難易度（コア施策）

- 資料請求ファネルの質改善（フォーム設計、期待値コントロール）
  → クライアント側の営業プロセスとの連携が必要
- LINE CRM設計（セグメント配信・ステップ配信）
  → 配信シナリオの設計工数はかかるが、技術的には実装可能
- 共働きターゲット向けコンテンツ制作（間取り提案、施工事例動画）
  → 撮影・編集の工数がかかるが、制作費の優先配分で対応可能

### 高インパクト x 高難易度（戦略的投資）

- Instagram運用の本格化（オーナーコンテンツの継続的な制作・運用体制構築）
  → 効果は高いが、オーナーの協力確保、撮影体制、継続的な運用体制の構築が必要
- アトリビューション分析の導入
  → チャネル横断の効果測定基盤がないと、予算配分の最適化判断に限界がある

### 中インパクト x 低難易度（余力があれば実施）

- 競合クリエイティブ分析に基づく差別化ポジショニングの提示
  → 鈴木氏がすでに競合LP・バナーを収集済み。分析の深掘りは可能

### 中インパクト x 高難易度（中長期検討）

- ブランド全体のデジタル体験刷新（LP単体ではなくサイト全体のリニューアル）
  → 今回の予算・スコープでは収まらない可能性が高いが、中長期提案として言及する価値あり

## D. 議事録の「行間」から読み取れる未言語化の課題

### 1. Instagram偏重リスクへの警鐘が必要

社長が「Instagramは費用対効果が一番良い」と発言しているが、この評価がラストクリック・アトリビューションに基づいている可能性が高い。検索広告やディスプレイ広告で認知・検討段階を経たユーザーが、最終的にInstagram経由で来場している可能性がある。社長の意向に沿いつつも、チャネル間の役割分担を正しく説明する提案が求められる。安易にInstagramに予算を寄せると、認知の土台が崩れるリスクがある。

### 2. 「指名案件だが他社検討あり」という微妙な立ち位置

競合プレゼンではないが、「提案内容に納得できなければ他も検討する」と釘を刺されている。これは、前年の成果に対する不満が蓄積していることを示唆する。単なるメディアプランの提出ではなく、前年の課題を正面から認め、改善の根拠を示す「反省と進化」のストーリーが必要。

### 3. 営業プロセス（来場→成約）の課題には触れられていない

議事録では「来場しても成約に至らない」という発言があるが、これは広告・マーケティング側だけでは解決できない。来場後の営業トーク、モデルハウスの体験設計、見積もり提示のプロセスなど、クライアントの営業側の課題が含まれている可能性がある。提案時にこの境界線を明確にしないと、「広告を改善したのに成約が増えない」という不満が再発する。

### 4. 予算総額が前年と同額であることの意味

成果に不満がありながら予算を増やしていない。これは「まず同じ予算で改善を見せてほしい、それが確認できれば増額も検討する」というメッセージと読める。予算増の提案をするよりも、同じ予算内での配分最適化と効率改善にフォーカスすべき。

### 5. FGI（フォーカスグループインタビュー）を新規実施する余裕がない

「新しいFGIをやる時間はない」という発言は、提案期限が1ヶ月と短いことだけでなく、追加調査費用の確保が難しい状況を暗示している可能性がある。既存データの再分析で仮説を立てる力量が試されている。

### 6. クリエイティブの社内リソース・承認プロセスが不透明

「2年前に作ったLPを更新していない」という事実は、クライアント側にデジタルマーケティングの専任担当者がいない、もしくは意思決定が遅い体制であることを示唆する。オーナーコンテンツやInstagram運用を提案する場合、クライアント側の実行体制（誰が撮影許可を取るのか、誰が投稿を承認するのか）まで設計しないと、提案が実行されずに終わるリスクがある。

### 7. 「社長の意向」と「現場の実態」のギャップ

社長がInstagramに強い関心を示している一方、田中部長の発言からは、より構造的なファネル設計の必要性が読み取れる。社長の期待に応えつつも、データに基づいた合理的な提案を行うバランス感覚が必要。社長向けのプレゼンストーリーと、実務的に正しいメディアプランを両立させる設計が求められる。

### 8. オフライン施策への言及がゼロ

住宅メーカーにとって、折込チラシ、住宅展示場でのイベント、地域メディア（ラジオ・フリーペーパー等）は依然として重要なチャネルだが、議事録では一切触れられていない。クライアントがデジタルシフトを志向しているのか、それとも単にこの会議のスコープ外なのかは確認が必要。
