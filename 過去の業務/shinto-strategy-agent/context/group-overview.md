# 新東通信グループ 事業概要

## 基本情報
- グループ総従業員数：約300名
- 代表取締役社長：谷鉄也
- 経営方針：AIドリブン宣言（2026年8月までにAgent OS化推進）

## 事業ポートフォリオ

### 1. 広告事業（新東通信）
- 総合広告代理店としてのプランニング・メディアバイイング・クリエイティブ制作

### 2. PR事業（共同ピーアール）
- 東証スタンダード上場
- メディアリレーション、危機管理PR、戦略PR

### 3. インフルエンサーマーケティング事業（VAZ）
- Z世代・若年層女性特化のインフルエンサーネットワーク
- SNSマーケティング企画・実行

### 4. データソリューション事業（KeyWalker）
- データドリブンマーケティング支援
- 分析基盤の構築・運用

### 5. 地方広告ネットワーク（Meisis）
- 全国の地方広告代理店とのネットワーク
- 地方発の知見・ローカルインサイトの集約

## グループの競争優位
- 広告×PR×データ×インフルエンサーの4領域統合提案力
- 大手代理店にはない機動力 × 中小代理店にはない総合力
