# Meisis プロフィール

## 基本情報
- 新東通信グループの地方広告ネットワーク事業を担う

## 提供サービス
- 何を：全国の地方広告代理店ネットワークを通じた地域密着型マーケティング支援
- 誰に：全国展開企業の地方戦略、地方自治体、地方企業
- どうやって：各地域の有力代理店とのパートナーシップによるローカルインサイト活用

## 強み
- 東京では見えない地方の生活者リアリティの把握
- 全国カバレッジとローカル深度の両立
- 地方発の成功パターン・知恵の蓄積
