# ばえめし Meta API システムユーザートークン移行手順

作成日: 2026-08-18
期限: **2026-08-30（土）14:48** に現行の個人トークンが失効（それまでに移行完了が必要）

## 背景

- ばえめし（@baemeshi_official）の日次レポート自動生成（広告消化額・CTR・CPF・フォロワー数を毎朝メール送信）は、谷会長のローカルマシン上の Claude Code で稼働中。
- 現行トークンは個人アカウント紐づけの60日トークンで、8/30に失効する。
- ドン・キンボールさんが Meta ビジネスマネージャーでシステムユーザーを作成し、**無期限のシステムユーザートークン**を発行済み（2026-08-18 のメール参照）。
- 本フォルダは、そのトークンへの差し替えをローカルで安全に行うためのキット。

## ⚠️ 重要（セキュリティ）

- **トークンは絶対にGitHubにコミットしない**（このリポジトリは公開リポジトリ。コミットするとトークンが世界に公開され、GitHubのシークレット検出でMeta側が自動失効させる）。
- トークンはローカルの `.env` ファイル等、レポートシステムが現在トークンを読んでいる場所だけに保存する。
- 万一漏えいした場合は、ビジネスマネージャー →「システムユーザー」→ 該当トークンを失効させ、再発行する。

## 移行手順（ローカルマシンで実行）

日次レポートが動いているマシンで、レポートシステムのフォルダを開いた Claude Code に以下を貼り付ける:

```
ばえめしの日次レポートで使っているMeta/Instagram APIのトークンを、新しいシステムユーザートークンに差し替えてください。

1. 現在トークンが保存されている場所（.env や設定ファイル）を特定して、旧トークンをバックアップした上で新トークンに置換
2. vision-app リポジトリの baemeshi-token-migration/verify_meta_token.sh で新トークンを検証
   （META_SYSTEM_USER_TOKEN='新トークン' bash verify_meta_token.sh）
3. 日次レポートを1回手動実行して、メールが正常に届くことを確認
4. 問題なければ旧トークンのバックアップを削除

新トークン: （ここにドンさんのメールのトークンを貼る）
```

## 検証スクリプト単体の使い方

```bash
META_SYSTEM_USER_TOKEN='EAA...' bash verify_meta_token.sh
```

確認される項目:

1. トークンが有効か（/me）
2. 無期限トークンか・必要スコープが揃っているか（/debug_token）
   - 必要スコープ: instagram_basic / instagram_manage_insights / instagram_content_publish / ads_read / pages_show_list / pages_read_engagement
3. ばえめしIGアカウント（ID: 17841450708912874）のプロフィール・インサイト取得
4. 広告アカウント（act_598774024775324）の情報・消化額取得
5. Facebookページ一覧の取得

すべて ✓ になれば差し替えOK。✗ がある場合は、出力されたエラーをドンさんに共有してシステムユーザーへのアセット割当を確認する。

## なぜクラウド側（このセッション）で完結できないか

- レポートシステム本体はローカルマシンにあり、GitHub上のどのリポジトリにも含まれていない。
- クラウド実行環境のネットワークポリシーで graph.facebook.com への接続がブロックされているため、トークン検証もローカルで行う必要がある。
