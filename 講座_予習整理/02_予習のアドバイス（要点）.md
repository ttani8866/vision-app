# 予習のアドバイス（やりとりの要点）

## ユーザーの前提

- 講座: チャエンさんの非エンジニア向け Claude Code 講座を受講予定
- **既に Claude Code 上でマルチエージェント（マルチエージェント機能）を実装した経験あり**

## 講座側が求める最低ライン

1. **当日までに Cursor と Claude Code のセットアップ完了**（案内どおり）
2. 申し込み後に配られる **事前セットアップ動画（Mac / Windows）** を最優先で実施
3. **Cursor**: 案内では無料（Hobby）で可とされていた
4. **Claude Code**: **Anthropic の Pro / Max** が別途必要、と FAQ で触れられていた

## マルチエージェント経験者向けの予習の仕方

講座は「開発」より **業務への組み込み** が主眼のため、次を用意しておくと当日の取りこぼしが減る、というアドバイスをした。

### 1. 自分のマルチエージェントを「業務ストーリー」で話せるようにする

- 何を並列化し、入力・成果物をどうしたか
- **非エンジニア向けに 2〜3 分で説明できるメモを 1 枚**
- 講座の「棚卸し」「Skills 化」のパートでそのまま活きる

### 2. 講座キーワードを、自分の環境で一度だけ触る

- **CLAUDE.md**（プロジェクトの「地図」）
- **Skills**（再現用テンプレ）
- **MCP**

実装経験があっても、「業務用の書き方・置き方」は別物になりやすい、という整理。

**具体的な小さな予習例**

- 予習用フォルダを 1 つ作り、短い `CLAUDE.md`（ルール・用語・出力形式だけ）を置いてみる
- **よく繰り返す作業を 1 つ**選び、「手順名＋チェックリスト」レベルで **Skill 化の素案**を書く

### 3. ワークショップ用の「生データ」を用意する

第 2 部でフォルダ整理・ドキュメント・**会議メモから Excel** などが想定されていた。

- 実在するが **個人情報を除いた** 会議メモや雑フォルダの**コピー**
- 「こういう Excel が欲しい」という **列・シートのイメージ**

### 4. 「ブラウザの Claude」との違いを一文で言語化する

案内では強みとして次などが挙がっていた。

- ファイル操作
- 長期コンテキスト（`CLAUDE.md` 等）
- 再現性（Skills）

自分のマルチエージェントは、どの点が **ローカル／プロジェクト単位** で効いているかを一文で書いておくと、第 1 部の理解が早い。

### 5. Notion の予習メモ

Notion が開けるなら、**主催者のチェックリストや推奨手順に従うのが最優先**。

## 時間の使い方（優先度の目安）

| 優先度 | 内容 |
|--------|------|
| 高 | セットアップ動画どおりに Cursor + Claude Code + 課金プランの確認 |
| 高 | ワーク用のサンプルデータ（メモ・フォルダ）の準備 |
| 中 | CLAUDE.md 1 枚・Skill 素案 1 本 |
| 低 | キーワードの網羅的なインプット（当日の説明と被る） |

## 一言のまとめ（やりとりの結論）

マルチエージェントまで作れている場合、**ツール操作の予習より「業務課題・データ・再現したい手順」の用意**を厚めにすると、講座のゴール（業務への組み込み）に合う。
