# ir-video-autogen — IR／PR動画 自動生成スキル

## Why（目的）
共同ピーアール（上場PR会社）および上場クライアントの IR・PR コミュニケーションを、決算開示資料からそのまま動画化することで、開示当日に「資料 + 解説動画」のセット配信を可能にする。投資家・記者・社員向けのリーチを拡張し、難解な決算ハイライトを短時間で理解させる。

最終成果物は次の3点。

- `out/{slug}/video.mp4` — 1080p / 16:9 / 3〜5分のナレーション付き動画
- `out/{slug}/script.md` — 採用された原稿（チェック済み）
- `out/{slug}/captions.srt` — 日本語字幕（英語版オプション）

コードネーム: ELEMOTION（Eleven Labs ＋ Remotion）

## When to use（起動条件）
- 「IR動画作って」「決算動画化」「開示資料を動画に」
- 「決算ハイライトを3分にまとめて」「IRをショート動画に」
- 適時開示・決算短信・統合報告書 → 解説動画化の依頼
- 上場クライアントの株主総会向け説明動画

## When NOT to use（起動しない）
- 開示前の決算情報・業績見通しを含むリクエスト → 即停止し、開示済みかをユーザに確認
- 内部の業績シミュレーション、未開示の M&A 情報 → 受けない
- 個別投資家への投資推奨と受け取られ得る表現の依頼 → 受けない
- 法定開示そのものの代替（金商法・適時開示規則の正規ルートが必要） → 受けない

## Inputs（入力）
| 項目 | 必須 | 説明 |
|---|---|---|
| source | 必須 | 決算短信PDF／プレスリリースURL／開示資料テキスト のいずれか |
| company | 必須 | 対象企業名・証券コード（例: 共同ピーアール 2436） |
| period | 必須 | 対象期（例: 2026/3 通期、2026/6 第1四半期） |
| duration_sec | 任意 | 動画尺（既定 180秒、最大 300秒） |
| language | 任意 | `ja` / `en` / `ja+en`（既定 `ja`） |
| voice_style | 任意 | `news` / `calm` / `executive`（既定 `calm`） |
| dry_run | 任意 | true で原稿生成までで停止し、人手レビュー後にレンダリング実行 |

## Outputs（出力）
- `out/{slug}/video.mp4`
- `out/{slug}/script.md`
- `out/{slug}/captions.srt`
- `out/{slug}/review_checklist.md` — コンプラ確認用チェックリスト
- `out/{slug}/sources.md` — 引用した開示資料へのリンクと取得日時

## Guardrails（コンプライアンス）
本スキルは上場会社の情報発信を扱うため、以下を厳守する。

- 入力ソースは「既に開示された資料」のみを許容。開示前資料が混在していたらユーザに確認を取る
- 数値・固有名詞は原典からの一字一句コピーを優先し、推測補完は禁止
- 業績見通しに関する文言は原典の表現をそのまま使用（曖昧な意訳を禁止）
- ナレーション末尾に必ず免責文を自動付与（「本動画は開示資料を要約したものであり、投資勧誘を目的とするものではありません」）
- 出典スライド（参照ページ）を字幕に小さく明記
- `review_checklist.md` を生成し、公開前に IR 担当・法務・PR 責任者の3者チェックを促す

## Workflow（処理フロー）
1. **資料パース**: PDF/URL から本文と数値表を構造化抽出
2. **原稿生成**: Claude が duration_sec に合わせて IR 文体で台本起案。冒頭・本論・結論・免責の4ブロック構成
3. **コンプラ自己チェック**: 開示前情報・推測表現・誤数値の検出を内部で行い、検出時は停止
4. **dry_run 分岐**: dry_run=true なら script.md と review_checklist.md のみ出力して終了
5. **音声生成**: ElevenLabs（multilingual v2 / v3）で日本語ナレーション、必要なら英語版も生成。ワード単位タイムスタンプ取得
6. **動画生成**: Remotion で
   - 表紙（社名・期間・ロゴ）
   - キーメッセージスライド（決算ハイライト3〜5項目を大きく）
   - 数値ビジュアル（売上／営業利益／重点KPI のテロップ）
   - 章タイトル＋ナレーション同期字幕
   - 免責スライド
7. **レンダー**: 1080p / 30fps / mp4 + srt 出力
8. **アーカイブ**: out/{slug}/ に格納、Slack `#ir-video-log` に完了通知

## Tech stack
- Claude Code（原稿生成・コンプラチェック）
- ElevenLabs API（`eleven_multilingual_v2` または `eleven_v3`）
- Remotion（@remotion/cli、@remotion/captions、@remotion/google-fonts）
- 環境変数: `ELEVENLABS_API_KEY`（コミット禁止、各環境で設定）

## Templates
`templates/` 配下に以下のRemotionプロジェクトを保持予定。
- `templates/earnings-3min/` — 決算ハイライト3分尺
- `templates/release-90s/` — プレスリリース90秒尺
- `templates/agm-5min/` — 株主総会向け5分尺

## サンプルキーワード
- 「2026年3月期通期決算を3分動画にまとめて」
- 「このリリースをIR動画化して」
- 「先週の適時開示を90秒のショート動画にして」

## 注意
- 本スキルは共同ピーアール社内および契約クライアント向けの内製運用を想定。外販SaaS化は別途リーガルレビュー必須
- 公開前に必ず `review_checklist.md` の3者承認サインを得ること
