## エステティック通信 特定ルール

| 項目 | ルール |
|------|--------|
| 文体 | ～である・～だ調。インタビュー「　」内はです・ます調 |
| 改行 | 文頭は頭下げ。見出し・キャッチコピーは文章の区切りの良いところで |
| 句点 | 見出し・キャッチコピー・「　」文末には不要 |
| 三点 | …… （全角2つ） |
| 「　」 | インタビューのせりふ。成分名・サービスなどパッケージ化できない固有名詞にも使用 |
| 『　』 | 製品名は必ず使用。TV番組名・曲名・雑誌名にも使用 |
| 　 | 強調に使用 |
| 数字 | 横組みは洋数字（半角）。3桁以上は縦書き |
| 金額 | 基本：0,0000円。10万以上は「万・億」をつける。スペックはすべて算用数字 |
| 英字 | 半角（縦組みは全角） |
| 年号 | 西暦表記（法令は元号） |
| 単位 | 記号使用禁止（文字化け防止）→ kg、cm など半角英字 |
| 分数 | 「4分の3」「10分の1」など。料理記事などは「3/4」可 |
| 住所 | 都道府県はじまり |
| 株式会社 | （株）。社名欄は「株式会社」。コメント内・キャッチは社名のみ可 |
| ○カ月・○カ所 | 大きい「カ」で表記。×ヵ ×ケ |
| ロングセラー | 10年以上続いたもの |
| 製品 | 「製品」で統一。「商品」は不可。「アイテム」は文脈による |
| 機器 | 「○○機器」で統一。「○○機械」は不可 |
| 注釈 | ＊全角。複数の場合は数字も全角 |
| スペック | 製品名［全角スペース］内容量orサイズ［／全角］価格 |
| 価格 | 税込で統一。表記は（税込）。サロン価格を記載が基本 |

|------|------|-----|
| おきゃくさま | お客様 | × お客さま |
| ください | ください | × 下さい |
| さま | 様 | × さま |
