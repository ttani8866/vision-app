# estsu-award — 日本美容企業大賞 誌面テキスト生成

「日本美容企業大賞」の受賞企業について、エステティック通信掲載用のテキストを生成するスキル。
企業情報（URLまたはエントリーシート）と審査評価結果を入力として、規定フォーマットのテキストを出力する。

## コンテキスト参照（必須）

- `.claude/skills/estsu/context/tone-and-manner.md`
- `.claude/skills/estsu/context/hyoki-manual.md`

## 入力素材

以下を添付・入力すること。

1. 企業情報（URLまたはエントリーシートPDF）
2. 審査評価結果（各評価軸のスコアと評点理由・総括テキスト）

## 実行手順

### Step 1 — 企業情報の抽出
URLまたは添付ファイルから以下を抽出する。
- 会社名
- MAIL または TEL
- 設立年月
- 代表者名
- 本社所在地
- 事業内容（130文字要約、だ・である調）

### Step 2 — 評価軸のピックアップ
審査評価の各評価軸（通常5軸）から、スコアが高い、または総括で特に言及されている2軸を選定する。

### Step 3 — テキスト生成
以下フォーマットで出力する。

## 出力フォーマット（文字数厳守）

```
[会社名]
MAIL: [メール] または TEL: [電話番号]

会社概要
設立年月　[設立年月]
代表者　[代表者名]
本社所在地　[住所]

事業内容
[130文字程度。だ・である調]

[部門カテゴリ（例：モノ／サービス／ヒト）]
[受賞部門名]

見出し：
[部門評価を総括する見出し。34文字以内。17文字前後で改行]

評価ポイント
✔︎[評価軸1の要約見出し。26文字以内。13文字前後で改行]
[評価軸1の解説本文。54文字以内。だ・である調]

評価ポイント
✔︎[評価軸2の要約見出し。26文字以内。13文字前後で改行]
[評価軸2の解説本文。54文字以内。だ・である調]
```

複数部門がある場合は部門カテゴリから下を繰り返す。

## 実行ルール

- 敬語（です・ます調）は一切使用しない
- 体言止め、または「だ・である」調を徹底する
- 見出しはサロンオーナーに響く言葉を選ぶ
- 審査評価の内容を正確に反映する。誇張・補完禁止
- 製品・サービス名は『　』でくくる
