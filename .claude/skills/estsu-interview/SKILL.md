# estsu-interview — タイアップ記事（取材・音声→原稿）

エステティック通信のタイアップ記事を音声文字起こしまたは取材メモから原稿化するスキル。

## コンテキスト参照（必須）

このスキルを実行する前に、以下の2ファイルを必ず読み込むこと。

- `.claude/skills/estsu/context/tone-and-manner.md`
- `.claude/skills/estsu/context/hyoki-manual.md`

## 入力素材

以下のいずれかを添付・貼り付けすること。

- 音声文字起こしテキスト（Google AI Studio 出力推奨）
- 取材メモ・ヒアリングメモ
- インタビュー記録

## 実行手順

### Step 1 — 原稿生成

以下のルールで第三者目線の記事原稿を生成する。

- 文字数：依頼に指定がない場合は320字
- 視点：第三者目線（記者が書く体裁）
- 発言の引用：「　」を使用。文末句点不要
- 事実の改変禁止：文字起こしに存在しない情報を補完しない
- 口語→文語変換：発言内容の要約・省略・意味変更はしない

### Step 2 — 表記チェック

生成した原稿を `hyoki-manual.md` の辞典に照らして自動チェックし、以下を修正する。

- NG表記の修正（例：挨拶→あいさつ、頑張る→がんばる）
- 薬機法・景表法違反ワードの適法表現への変換
- 製品名の『　』括り確認
- 数字・単位表記の統一

### Step 3 — 出力

修正済み原稿を出力する。修正箇所がある場合は末尾に修正一覧を付記する。

## 出力フォーマット

```
【原稿】
（本文）

【修正一覧】（修正がある場合のみ）
- 修正前：〇〇 → 修正後：〇〇（理由）
```

## 注意事項

- 発言者のプロフィール（役職・会社名）は文字起こしから取得すること
- 製品名・固有名詞は文字起こしに忠実に表記すること
- 推測で情報を補完しない。不明な箇所は【要確認】とマークする
