# 1% BODY — App Screens

肉体改造支援アプリ「1% BODY」の主要4画面を実装した静的サイト。
Claude Design プロジェクト `1% BODY App Screens.dc.html` を、依存のない
HTML / CSS / JS に落とし込んだもの。

- プロジェクト: https://claude.ai/design/p/c7af8efc-ee6c-47ea-8476-9cb8c7a13e4d
- デザインシステム: Workstyle Evolution Design System (`d3ef6969`)

## 要件定義書

`requirements.html` に、同プロジェクトの「1% BODY 要件定義.dc.html」（v0.1、2026/09/04、MVP版）を
ドキュメントページとして同梱している。ツールバー右端の「要件定義書」から開く。
US Letter 幅（8.5in・余白0.75in）の紙面レイアウトで、ブラウザの印刷からそのままPDF化できる。

## 見かた

```bash
npx -y http-server one-percent-body -p 8140 -c-1
```

`http://localhost:8140` を開く。`index.html` を直接ブラウザで開いても表示できる。
（Claude Code からは `.claude/launch.json` の `one-percent-body` で起動する）

デスクトップでは4画面をキャンバス上に横並びで表示し、
上部ツールバーから各画面へスクロールする。1024px 以下では縦積みになる。

## 構成

```
one-percent-body/
├── index.html              4画面ぶんのマークアップ
├── requirements.html       要件定義書（ドキュメントページ）
├── assets/css/tokens.css   デザインシステムのトークン（色・タイポ・余白・影・モーション）
├── assets/css/app.css      デバイスフレームと画面コンポーネント
├── assets/css/doc.css      要件定義書の紙面レイアウトと印刷スタイル
└── assets/js/main.js       ステータスバー等の端末装飾の注入、ツールバーのスクロール制御
```

姉妹プロダクト「FACE AGE SCORE」（AI肌診断）は同じ Claude Design プロジェクト同梱の別画面で、
`../face-age-score/` に独立した静的サイトとして実装している。

## デザインからの実装メモ

- デザイン上のインラインスタイルは、`tokens.css` のトークンを参照するクラスへ整理した。
  生の hex 値は `app.css` の `--on-shell-*`（ダークヘッダー上でのみ使う派生トークン）を除いて残していない。
- Claude Design 固有の要素は次のように置き換えた。
  - `<x-import ... IOSDevice>` → `.device`（CSS のみで組んだ iOS フレーム）
  - `<image-slot>` → `.slot`（破線プレースホルダー。`<img>` を入れれば実写に差し替わる）
- 横スクロールはキャンバス側に持たせている。body を横に流すと
  `position:sticky` のツールバーが一緒に流れてしまうため。
- 数値はすべて JetBrains Mono・tabular-nums、本文は Noto Sans JP。
  デザインシステムの「文章はヒューマニスト、データは等幅」という原則に従う。

## 注意事項（デザイン内の表記をそのまま実装している）

- 「1% BODY」は独自の複合評価基準であり、統計的な上位1%の証明ではない。
- 写真分析の出力はすべて推定・参考評価であり、医療診断ではない。
