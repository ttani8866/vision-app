0. データ取得経路についての注記
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
本レポートの広告実績は meta-ads MCP 経由では取得できていない。
MCP サーバーが接続失敗（Connection closed）で起動せず、原因は
~/.claude.json の meta-ads 設定にある META_ACCESS_TOKEN の失効。

  Error validating access token: Session has expired on
  Wednesday, 26-Aug-26 08:08:49 PDT.（code 190 / subcode 463）

一方、IG 用のシステムユーザートークン（BAEMESHI_IG_USER_TOKEN、
アプリ 3182453308622661）を debug_token で確認したところ、
ads_read / ads_management / business_management の権限を保持していた。
そのため今回に限り、このトークンで読み取り専用の insights 取得を行い、
実績値を確定させている。書き込み系の操作は一切していない。

恒久対応は、meta-ads MCP の META_ACCESS_TOKEN を
このシステムユーザートークンに差し替えること。これで同種の失効は解消する。
なお当該システムユーザートークンの expires_at は 1793972220
（2026-11-06 頃）であり、無期限ではない点に注意が必要。

CPF 算出上の注意
  フォロワー数は日次スナップショットの差分であり、取得時刻のずれ分だけ
  対象日とわずかに前後する。単日 10 人という母数の小ささから、

  日次の細かい増減を評価するには精度が足りない。

4. 所見
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CPF 216.6 円は過去実績（157.8〜294.7 円）の帯の中で、悪くない水準に収まった。
ただしフォロワー増が10人／日にとどまる一方でリンククリックは308あり、
クリックはついているのにフォローに転換していない構造は8月から変わっていない。
トラフィック目的の配信である以上、フォロー導線そのものの検証が引き続き論点。

配信品質は前日より改善している。CTR 6.66% → 7.72%、CPC 7.89 円 → 7.44 円。
一方で CPM は 525.66 円 → 574.99 円に上昇し、インプレッションは4,307→3,767に減った。
枠が高くなった分を CTR の改善で吸収した形で、クリック数はほぼ横ばい（287→291）。

配信の偏りは、フリークエンシー1.06と低く同一ユーザーへの重複露出は問題ない。
むしろ問題は広告本数側で、消化の76.9%が1本（2026/6/30）に寄っている。
CTR で見ると 2026/6/28 の10.74%、2026/4/23 の13.95% のほうが高く、
配信量の配分と成績が一致していない。予算配分の見直し余地がある。
なお日予算 2,000 円に対し 108.3% と超過しているが、Meta の日予算は
日次で最大125%まで変動するため、単日の超過自体は異常ではない。
